使用PE备份还原Windows教程

2026-03-20
点击后调用浏览器打印，选择"另存为PDF"

软件准备

  1. ventoy https://gitee.com/longpanda/Ventoy/releases/download/v1.1.09/ventoy-1.1.09-windows.zip
  2. pe镜像 仅提供局域网下载，不提供公网下载。
    点击下载WindowsPE64_SKS.iso
    或是到极空间Nas网盘下载产品部:\OSImages-系统镜像\PE\WindowsPE64_SKS.iso

制作PE启动U盘

  1. 插上U盘（U盘需要格式化，请提前做好数据备份）

  2. 解压ventoy到桌面

  3. 打开Ventoy2Disk

  4. 点击安装一键制作

  5. 复制WindowsPE64_SKS.iso到U盘

启动PE系统

  1. 插上U盘
  2. 开机按键盘del进入BIOS
  3. 到Exit & Save界面，选择U盘启动
  4. 其余选项默认回车直到进入PE系统

备份系统

  1. 打开OneKey Ghost
  2. 选择备份分区，选择镜像保存路径，默认选中的系统盘即可
  3. 等待备份完成
  4. 备份完成

还原系统

  1. 打开OneKey Ghost
  2. 选择还原分区，选择镜像保存路径，选择需要进行还原的分区

    注：如果选择的当前分区没有系统(既没有引导)，需要勾选引导修复选项
  3. 等待还原完成
  4. 还原完成，重启
