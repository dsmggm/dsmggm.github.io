mkisofs打包iso镜像命令

mkisofs -r -v -V "卷标" -eltorito-alt-boot -e boot/grub/efi.img -no-emul-boot -o ../xxx.iso . -T 生成翻译表，优化 ISO 文件在不同系统间的兼容性。 -r 使用 Rock Ridge 扩展，保留 Unix/Linux 文件属性（如权限、所有者等）。这对于 Linux 系统的 ISO 非常重要。 -v 显示详细输出，便于调试和查看进度。 -V “卷标” 设置 ISO 的卷标（Volume Label），即光盘的名称。 -eltorito-alt-boot 指定替代的引导映像，用于支持多种引导方式。 -e boot/grub/efi.img 指定 EFI 引导映像文件路径，使 ISO 支持 UEFI 模式启动。 -no-emul-boot 设置为无模拟引导模式，直接加载引导映像。 -o ../xxx.iso 指定输出 ISO 文件的路径和名称。 . 指定要打包的源目录（当前目录）。
