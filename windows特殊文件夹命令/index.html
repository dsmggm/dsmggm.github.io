windows特殊文件夹命令

2025-11-19
命令 作用说明
shell: desktop 用户桌面文件夹
shell: common desktop 公共用户桌面文件夹
shell:sendto “发送到"菜单中的文件夹
shell:startup 用户登陆自启动文件夹
shell:common startup 全部用户登陆启动文件夹
shell:programs 开始菜单中的程序文件夹
shell:common programs 全部用户开始菜单中的程序文件夹
shell:appdata 应用程序数据文件夹，存储应用程序的配置文件等
shell:recent 最近使用的文件夹
shell:favorites 收藏文件夹
shell:fonts 字体文件夹
shell:templates 模板文件夹
shell:my music 用户音乐文件夹
shell:my pictures 用户图片文件夹
shell:videos 用户视频文件夹
shell:start menu 用户开始菜单文件夹
shell:appsfolder 全部已安装应用文件夹
shell:quick launch 开始菜单快速启动文件夹，主要是里面的user pinned(隐藏的)-TaskBar文件夹是固定任务栏的文件夹
shell:programfiles 程序安装目录C:\Program Files
shell:programfilesx86 程序安装目录C:\Program Files (x86)
shell:programfilescommon 程序安装目录C:\Program Files\Common Files
