linux基础命令列表

常用操作命令

命令 说明
ls List (列出文件和目录如果使用-l参数，则显示文件和目录的详细信息)
pwd print working directory(查看当前目录)
cd Change Directory (切换目录)
mkkdir Make Directory (创建目录)
touch 创建文件
cp Copy (复制)
mv Move (移动/重命名)
rm Remove (删除)
cat Catenate (查看文件内容)
grep Global Regular Expression Print (搜索)
find Find (查找)
less Less (查看文件内容)
ps Print Status (查看进程状态)
kill Kill (结束进程)
top/htop 查看进程状态
du Disk Usage (查看磁盘使用情况)
free Free Memory (查看内存使用情况)
tar Tape Archive (打包/解包)
ping ping (测试网络连接)
sudo Super User do (以管理员权限执行)
chmod Change Mode (修改文件权限)
passwd PassWord (修改密码)
demsg (查看内核日志)
systemctl System Control (查看系统信息)
journalctl (查看和管理系统服务日志)
| 管道连接
–help 查看命令的帮助信息

ip/ipconfig 查看网络信息
nmcli/nmtui 查看网络信息
netplan 调用工具netplan
